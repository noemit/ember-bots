**Status: owner-authorized release process in progress; not a published release.**

- Ember candidate: **1.24.0**; included Kiln candidate: **1.12.0**.
- Previous public release verified on GitHub: **v1.23.0**, published 2026-11-14.
- Scope: changes merged on main through `0f8f6e4`, plus this version/changelog preparation.
- Versioning: a minor bump for the complete feature batch, not one bump per development commit.
- The owner authorized beginning the release process on 2026-11-15. Tagging the reviewed commit
  and assembling candidate artifacts in a draft are in scope. Latest promotion, website deployment

The [Ember changelog](../../CHANGELOG.md) and [Kiln changelog](../../packages/kiln/CHANGELOG.md)
are the release notes. [RELEASES.md](../../RELEASES.md) is the artifact and promotion contract;
[updating](../updating.md) contains signing and native verification requirements.

## Scope boundaries

Included: immutable Questions answers and appended context, worker lifecycle/outcome safeguards, compact Tasks, grounded conversation names, global
blob style, procedural Mosaic activity, annotation Save/Discard, Ultra Delegator model defaults,
daily update checks, the top-of-list folder action, muted-chat and outage fixes, context advice,
and the Stop/queue/YEET handoff.

Not included: the unfinished per-message queued-model isolation,
ordered draggable compaction, secure file previews or an unverified rail-gap fix. Their dirty
worktrees are not part of this candidate. No unrelated working-tree edits were adopted.
