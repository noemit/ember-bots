## Scope boundaries

Included: immutable Questions answers and appended context, worker lifecycle/outcome safeguards, compact Tasks, grounded conversation names, global
blob style, procedural Mosaic activity, annotation Save/Discard, Ultra Delegator model defaults,
daily update checks, the top-of-list folder action, muted-chat and outage fixes, context advice,
and the Stop/queue/YEET handoff.

Not included: the unfinished per-message queued-model isolation,
ordered draggable compaction, secure file previews or an unverified rail-gap fix. Their dirty
worktrees are not part of this candidate. No unrelated working-tree edits were adopted.
